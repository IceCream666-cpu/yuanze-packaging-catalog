员工可查询历史产品与报价、组合筛选、上传图片找相似、收藏、对比、保存个人选型方案和查看实物样品；管理员可维护产品字段、图片、分类、网站文字、样品、方案及员工账号，进行 CSV／XLSX 导入、导出和历史版本恢复。原员工账号保持员工权限，不会自动成为管理员。操作说明见 [ADMIN_GUIDE.md](ADMIN_GUIDE.md)。

会话保存在 `YZ_STATE/auth-sessions/sessions.sqlite`，有效期仍为 8 小时；常规服务重启保留会话，主动退出、改密码或停用账号仍会撤销。日志包含状态码、认证原因与请求编号，不记录密码或 Cookie。新域名在本机 Safari/Chrome 已验证，但部分公网请求仍被阿里云接入层拦截；不要将本机可用等同于所有设备均可用。

原始资料由 `private/catalog.json`、本次增量底稿 `private/materials-20260924.json` 与 `private/media/` 提供。当前产品、用户、设置和业务记录持久保存在 `YZ_STATE` 的 SQLite 数据库；把底稿放入 release 不等于完成数据库导入。后台图片进入状态目录的 `uploads/`，图库变更会自动更新动态图片索引；发布新代码不覆盖状态目录。

## 2026-10-09 移动加载优化

服务端分页需要 Python 现有依赖和 Node.js 22+（`node` 在 PATH，或配置 `NODE_BIN`）。私有查询工作进程从 SQLite 生成目录、复用浏览器相同的查询逻辑；它不对外监听端口，不使用外部模型或图片 API。没有 Node 时会话返回 `catalogPaging=false`，旧全库路径可用。

`YZ_STATE/image-thumbnails/` 和既有 `client-media-cache/` 保存可重建衍生图，不属于产品数据，不提交 Git。列表的 `thumb=1` 不改变原图及下载；静态文件和图片使用 `private, no-cache`／ETag，敏感图片的授权检查先于 304。JSON、HTML、登录和会话仍为 no-store。GET／HEAD 可复用 HTTP/1.1 上游连接，POST 关闭连接；正式 Nginx 拟启用 HTTP/2 和独立 keepalive upstream。发布时先检查 Node 可执行、预热索引和三角色安全边界，数据库、账号、上传及原图保持。验收见 `../docs/手机端加载优化-20261009.md`。
