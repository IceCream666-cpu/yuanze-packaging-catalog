# 源泽业务协同 · 参考系统

这是用于讨论需求、页面和操作流程的前端参考网站。所有客户、订单、金额与配方均为虚构演示数据。数据只在本次页面中保留，刷新后重置。

## 打开方式

最简单：直接用浏览器打开随包提供的“源泽业务协同-参考网站.html”，无需安装任何依赖。

开发预览：在 site 目录运行 `python3 -m http.server 4173 --directory dist`，浏览器访问 http://localhost:4173 。

## 建议体验顺序

1. 在样品中心打开“轻盈保湿面霜”，查看同一主单的历轮版本。
2. 业务员审核可寄出，再登记模拟寄样，记录客户反馈或发起下一轮调整。
3. 切换实验室视角，接单、制作、提交配方版本和制作意见。
4. 切回业务员审核，体验内部返工与新增客户打样轮次的区别。
5. 客户确认后创建演示大货订单，体验采购生产、品质仓库和回款记录。
6. 切换国外业务，查看独立筛选后的业务资料。

## 交给 Claude Code

先阅读需求开发任务书，再查看 site/dist 中的界面和流程。此代码是交互参考，并非正式业务后台；后续需要实现数据库、真实身份权限、配方与附件管理、审批、审计、备份，以及经确认的业务规则。演示岗位切换没有权限保护含义。

源代码：dist/index.html、dist/style.css、dist/app.js、dist/workflow.mjs。
流程检查：安装 Node.js 后运行 `node --test test-workflow.mjs`。

当前支持国内/国外板块、11个业务页面、新建样品、同一主单多轮调整、内部返工、审核寄样、客户确认、演示大货与库存回款协同。
