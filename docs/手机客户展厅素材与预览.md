# 手机客户展厅素材与预览

本轮为 2026-09-30 用户补充素材后的本地设计预览，不改变正式网站路由、权限、账号或数据库。源代码和这批公司展示素材同步到项目私有 Git 仓库，供跨设备接续。

## 打开预览

预览目录：[mobile-client-preview](mobile-client-preview/index.html)。其中的 HTML、CSS、JavaScript 和素材均使用相对路径，可直接在浏览器打开 `index.html`；也可以在项目根目录运行：

```sh
python3 -m http.server 4318 --bind 127.0.0.1 --directory docs/mobile-client-preview
```

浏览器访问 `http://127.0.0.1:4318/`。只监听本机，不在公网提供无登录的展示。正式接入后，公司照片、证书预览和 PDF 下载也必须受到客户登录保护，不应直接把本目录挂到匿名静态路径。

## 公司简介与中英文

`mobile-client-preview/company-content.js` 保存用户提供的完整英文原文 `originalIntroductionEn`，以及中英文显示文案、照片和证书元数据。

显示文案保留“超过 30 个国家”“14 年配方经验”等用户提供信息。认证表述根据本批证书改为公司生产管理体系通过 Intertek 的 ISO 22716:2007 和 GMPC 认证，不写成单个产品获认证。

原文中的 “FDA-registered” 保留在来源字段中，当前显示文案暂未采用：本次提供的是 ISO/GMPC 证书，GMPC 引用 FDA 指南并不构成 FDA 注册凭据。若后续提供相关注册材料，应核对主体、范围及用词后再补入展示。

语言切换同时更新导航、公司简介、图片说明、证书 PNG 及原始 PDF 链接；不会重置公司简介的展开状态。语言偏好仅保存为本机预览专用键，不改变正式网站语言设置。

## 当前预览交互与后续接入

- 首页图文、真实公司图片、能力类目、14 年和 30 多国的简介重点、公司介绍及证书展示。
- 中文 / English 切换，照片和证书放大、关闭与焦点恢复；减少动态效果偏好被尊重。
- “产品”滚动到包材引导，“进入包材展厅”在新标签打开现有统一登录入口，不后台读取正式产品或会话。
- “联系”滚动到联系区。业务员、二维码、电话和统一接待资料尚未提供，因此不虚构联系方式或询盘提交成功状态。
- 本地预览尚未实现专属邀请链接、真实意向清单及管理员编辑首页素材；这些继续按照 [跨设备接续开发](跨设备接续开发.md) 中已确认方案实施。

回归入口：`tests/frontend/mobile-company-preview-tests.cjs`，已加入 `scripts/verify.py` 调用的前端测试集合；素材完整性和页面尺寸另由 `tests/test_mobile_materials.py` 检查。
