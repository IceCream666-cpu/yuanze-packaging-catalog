# 手机客户展厅素材与预览

本轮为 2026-09-30 用户补充素材后的本地设计预览，不改变正式网站路由、权限、账号或数据库。源代码和这批公司展示素材同步到项目私有 Git 仓库，供跨设备接续。

## 打开预览

预览目录：[mobile-client-preview](mobile-client-preview/index.html)。在项目根目录运行：

```sh
.venv/bin/python scripts/preview_customer_showroom.py --port 4319
```

浏览器访问 `http://127.0.0.1:4319/`。本轮改为三个独立分页，底栏用于切换视图，不再跳转同一长页的锚点。每个页面可以单独上下浏览，产品页保持挂载，切走再回来保留筛选、图片详情、收藏和意向清单。浏览器后退/前进也可切换分页。

预览服务器只监听本机，并只开放公司素材、客户前端和经过再次白名单过滤的客户数据。正式接入时，公司照片、证书及 PDF 也必须受登录保护。本预览没有修改线上路由和账号。

产品页复用 `server-reference/public/client.{html,js,css}`，数据快照来自当前线上客户安全接口：12 款获准展示的包材、12 张图片，保存于 Git 忽略的 `outputs/mobile-preview/catalog.json` 和 `client-media/`。不是全量员工数据库；不自动放行未获批原图。跨设备运行需重新取得客户安全快照，不能以员工目录或整个私有素材目录代替。不要用普通静态文件服务器打开此预览，产品接口需由上述脚本提供。

## 公司简介与中英文

`mobile-client-preview/company-content.js` 保存用户提供的完整英文原文 `originalIntroductionEn`，以及中英文显示文案、照片和证书元数据。

显示文案保留“超过 30 个国家”“14 年配方经验”等用户提供信息。认证表述根据本批证书改为公司生产管理体系通过 Intertek 的 ISO 22716:2007 和 GMPC 认证，不写成单个产品获认证。

原文中的 “FDA-registered” 保留在来源字段中，当前显示文案暂未采用：本次提供的是 ISO/GMPC 证书，GMPC 引用 FDA 指南并不构成 FDA 注册凭据。若后续提供相关注册材料，应核对主体、范围及用词后再补入展示。

语言切换同时更新导航、公司简介、图片说明、证书 PNG 及原始 PDF 链接；不会重置公司简介的展开状态。同源的首页、产品、联系三页共用语言偏好；切换语言不会重置当前页、产品筛选或咨询备注。

## 当前预览交互与后续接入

- **首页**：只介绍公司，包含真实展厅、前台、研发制造业务、公司简介和中英文证书。探索包材按钮切换到产品页。
- **产品**：编号搜索、侧栏分区、包材类型/分区/材质/容量/瓶型/用途多选、图片检索、多图详情、收藏、最多四款对比、意向清单、公开字段 CSV 导出、网格/列表及页容量/页码跳转。手机筛选可以展开和收起。
- **联系**：显示当前意向清单和可编辑需求，支持复制咨询内容供用户自行发送。电话号码、二维码及业务员资料尚未提供，明确显示待补充，不生成虚构联系人或成功提交记录。
- 供应商、价格、原始来源与内部字段不进入客户响应、详情、对比、导出或跨页面消息。图片仍须管理员批准，未实施去水印。
- 收藏及意向清单仅保存在本次浏览内存，刷新后清空，避免公用客户账号串单。独立客户身份及跨设备持久化仍待接入。
- 本地搜图使用既有 DINOv2 模型，对这 12 张获准图片独立建索引，瓶型结构权重 80%、颜色权重 20%；无外部模型 API，输入图片不保存。
- 已补客户专用 `POST /api/client/image-search` 后端源代码，保留登录、Origin、CSRF 与上传上限，输出重新校验当前获批状态。原员工搜图接口仍不可由客户访问。此改动尚未部署。
- 正式专属业务员邀请链接、公司接待信息、真实询盘接收及管理员编辑首页素材仍待接入。
- 当前预览以同源 iframe 复用客户产品界面。正式服务仍保留禁止嵌入的响应头；上线时必须将三页整合为受登录保护的客户路由，或仅对客户页面开放同源嵌入，不能全站取消嵌入保护。
- 搜图返回最多 48 个客户可见结果；正式后端在内部匹配后再次按当前图片审批过滤，最佳匹配图未获批时会安全排除该项。后续可建立独立客户图片索引以改善召回，不能放宽权限。

回归入口：`tests/frontend/mobile-company-preview-tests.cjs`、`tests/frontend/client-tools-tests.cjs`、`tests/test_customer_preview_server.py`、`server-reference/test_client_access.py`，统一通过 `scripts/verify.py`；素材完整性另由 `tests/test_mobile_materials.py` 检查。
