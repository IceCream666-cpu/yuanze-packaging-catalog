## 服务对象和目标

供源泽内部业务员查询包材、理解规格及历史采购报价、比较候选款式并整理选型资料。员工可见采购成本与供应商报价；这些权限不属于客户账号。业务端以快速检索和资料核对为主，客户首页的公司宣传内容不应占据员工日常选型入口。

现有包材库与“国内／国外订单、研发打样、完整配方、采购生产、仓库及财务”的早期业务演示是不同范围。后者尚未成为贯通真实业务的 ERP。

## 日常功能

| 功能 | 实际行为 |
| --- | --- |
| 文字与编号搜索 | 搜索系统编号、产品名称、材质和规格；系统编号有独立匹配，避免同名记录混淆 |
| 多选筛选 | 资料类型、面部／身体头部分区、包材类型、材质、规格、瓶型、用途、报价资料、图片状态和来源图册 |
| 分类侧栏 | 产品条目／图册线索／工艺参考、类型、材质、容量区间与来源；和顶部条件共用筛选状态 |
| 筛选逻辑 | 同一项满足任一值，不同项同时满足；可逐项清除或重置 |
| 翻页 | 上一页／下一页、页码按钮、输入页码，每页 20／40／80 条；保留翻页过渡和减少动态效果设置 |
| 图片检索 | 上传、粘贴或拖入图片，支持框选单个包材；瓶型结构优先，颜色印刷次之。结果需要核对规格，不能自动认定同款 |
| 展示方式 | 图片图库与资料表格切换；有多图时显示数量，详情可切换图片 |
| 产品详情 | 价格区域优先，随后产品细则、采购交付和原始出处；有明确参数才归纳，没有依据的字段保留空白 |
| 报价字段 | 采购价、含税价格、裸瓶、组件及工艺等按现有证据展示，不能将不同配置的历史报价相加生成未经确认的统一售价 |
| 收藏 | 按员工登录账号保存到服务端；与客户临时收藏不同。加载失败可重试，不妨碍目录搜索 |
| 对比与方案 | 最多四条候选对比；已选工具栏可保存个人选型方案，后端保留当时资料快照 |
| 导出 | 导出当前筛选列表的内部 CSV，含供应商和报价等资料；不作为客户版导出功能复用 |
| 中英文 | 按钮、系统状态和标准类目可切换；来源原文不伪装成已审核的英文翻译 |

印刷工艺、MOQ、货期和价格是可能随数量、颜色、工艺或配置变动的条件。系统展示依据，业务员仍须按本次需求复核，不能把历史报价解释为实时承诺。

## 产品与图片整理规则

- 产品编号由服务端分配并保持稳定；归档不回收编号。可追踪的内部 ID、版本号和原始证据要保留。
- 同系列不同规格分别记录；原图为同款多规格或未拆分线索时，保留说明与图片数量，不伪造精准图片对应。
- 真正原表没有对应图片的条目按用户已确认规则处理；“待细分／原图参考”不等于无图，不能自动批量删除。
- OCR 结果、历史报价、未核对尺寸和来源图页须保持出处。没有具体参数时不推测补填。
- 业务员看到内部图片不代表图片获准给客户看。客户展示由独立图片批准和安全数据出口控制。
- 管理员负责产品和图片维护、批量导入、账号、设置及归档恢复；普通业务员不应获得修改全库或管理账号的权限。

## 登录与稳定性边界

- 员工、管理员、客户由服务端确认角色，前端菜单不决定权限。统一登录后由应用分流，网关只透明转发，不再叠加根路径到登录页的重写。
- 员工在线会话默认不设数量上限，但这不等于服务器硬件有无限容量。管理员可创建各员工的独立账号并重置密码或停用。
- 常规应用重启保留有效会话；主动退出、账号停用、密码变更或认证版本变化使对应旧会话失效。
- 遇到网络错误、数据库不可用或代理错误时，应报告对应失败，不把所有问题显示为账号密码错误，不通过反复重置密码处理网络问题。
- 任何发布都要同时检查三种角色。更新客户界面不得改变员工账号、历史收藏、产品编号、采购数据或登录链路。
