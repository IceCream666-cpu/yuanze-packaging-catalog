# 产品详情设计预览（2026-10-10）

本轮仅创建独立前端 demo，供用户调整布局和行为。没有替换线上详情、调用正式 API、修改产品字段或新增客户图片批准。正式网站仍使用此前已发布的详情页。

## 布局

- 左侧保留主图、放大和图片下载；手机端图片在上、信息在下。
- 裸瓶价格置顶突出；材质、规格、MOQ、货期和通常用途只在核心参数区出现一次。截图对应的 50g、1.8 元、5000、20 天作为预览数据，材质保持空白。
- 工艺表涵盖裸瓶、丝印、烫金／烫银、注塑色、喷涂、蒙砂、电镀瓶身、电镀盖子、其他工艺。裸瓶行引用顶部基础资料，避免重复金额与交付参数；其他工艺起订、货期未填写时留空。
- 用户补充希望选工艺后估算。本 demo 使用截图示例：丝印 0.1 元／色、烫金／烫银 0.2 元／色、喷涂 0.5 元／色，明确标注演示标准。颜色数支持 1–9；金额按分计算。未填写费用的已选工艺或未录入裸瓶价格时不输出完整估算，不能将缺项当成零元。
- 材质差价、配件、税费、工艺对应 MOQ 与货期没有推算；估算只是演示，标准、不同材质规则及真实产品对应关系待后续补充。
- 现货信息独立展示；当前样例没有现货确认或现货图，保持未确认。
- 员工的供应商、联系人及完整原始报价收进折叠“内部资料”。供应商与联系人使用占位值；客户视角移除整块内部资料、价格与工艺费用估算，保留图片、参数及意向清单演示。
- 本地收藏、对比／意向仅改变本次预览状态；不写入数据库。中英文及未录入状态可切换。

## 本机打开

在工程根目录运行 `.venv/bin/python scripts/serve_product_detail_demo.py`，打开 `http://127.0.0.1:8901/`。

服务仅监听本机、白名单提供三个 demo 文件、现有 logo 和本机已优化的 `work/packaging-batch-20261006/round4/images/image19.png`；不提供目录浏览或 API，图片未复制进 Git。若新设备没有该私有素材，需要恢复该文件后预览。预览中的客户切换用于检查设计，不代替正式网站的服务端角色权限。
