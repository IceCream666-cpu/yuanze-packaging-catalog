# 常见用途与结构参考用途

## 整理口径

用户确认采用“原资料明确的用途，加上按包材结构整理的参考用途；参考用途单独标明”。同一包材可以关联多个用途，产品编号、底层记录和同系列规格不因用途而复制；侧栏继续按护理部位浏览，用途在现有多选检索中选择。

详情分为“资料标注用途”和“结构参考用途”。前者沿用原有产品范围内的名称、维护用途及明确用途字段；整页 OCR、供应商、图册文件名和图片说明不用于补认用途。后者只根据明确分类或瓶型给出选型建议，不表示实际配方适配已确认。用途不明、结构冲突、混合瓶罐、套装及独立配件不强行添加参考标签，也不由参考用途补认护理部位。

## 检索与展示

- 现有用途筛选同时检索两类用途。一个产品命中“洁面”和“护手霜”仍只出现一次；用途之间取任一，材质、规格等其他条件同时满足。
- 用途筛选结果中，有资料依据的匹配排在仅参考匹配之前；搜图仍保持图片相关性排序。
- 文字搜索支持“洗面奶／洁面”“手霜／护手霜”等常用说法及标准英文别名。按护理部位检索仍需有对应资料或人工标签，结构参考不自动改变部位。
- 卡片最多展示两个参考用途并标明剩余数量；详情、对比和列表导出分别显示两类用途，重复的资料用途不再另作参考展示。
- 客户仅获得标准白名单用途标签及已批准图片，供应商、报价、原文、内部记录 ID 等仍不输出。客户用语不是原资料自由文本的直接转发。

## 管理员维护

产品编辑、管理工具和批量操作均提供资料用途与参考用途。参考用途有三种状态：

| 模式 | 行为 | 存储／更新语义 |
| --- | --- | --- |
| 自动／恢复自动 | 根据当前明确结构计算 | 字段不存在；提交 null 表示移除旧人工覆盖 |
| 人工填写 | 用管理员填写的参考项替代自动建议 | 非空 referenceUses 列表 |
| 关闭 | 此产品不显示结构参考用途 | 空列表 [] |

修改其他产品字段不会把自动建议变成人工标签或关闭参考。批量操作需勾选待改字段，沿用版本冲突和审计；不改产品编号或原始来源。

管理员编辑用 CSV 模板新增“参考用途”列：写“自动”恢复自动，写 `[]` 关闭，写顿号／逗号／分号分隔的标签维护参考项；空格或空单元格保持已有状态。导出会区分“自动”、`[]` 和人工标签，便于后续原样导回。员工“当前列表”是选型报告，最后追加“资料用途”和“参考用途（选型参考）”，不是批量编辑模板。
