# 手机端包材库加载优化

## 原因与实测基线

2026-10-08 在正式域名、正确 Host／SNI、严格 TLS 校验下测试；本机 DNS 不稳定时仅对诊断连接指定当前主机 47.79.233.3，不修改系统 DNS。业务端原启动下载 11,851 条活动记录：JSON 解压后 33,437,444 字节，gzip 传输 1,375,284 字节。本机请求约 3.48–3.62 秒，服务器单次序列化约 1.79–1.91 秒。手机还须解析完整目录和生成搜索索引。

客户首批 24 条安全记录的响应为 9,289 字节，gzip 2,806 字节，但每次都重新投影／核验目录。服务器约 0.35–0.50 秒，本机 HTTPS 约 1.25–1.46 秒。手机 136 像素宽的卡片下载 1,303–1,549 像素的图片；六张抽样员工图为 146–211 KB，客户图为 103–171 KB。图片 no-store 导致重复访问重传；五张手机轮播背景约 1.1–1.2 MB／张。懒加载已存在，本轮保留。

这些是本机与服务器测量，不是实际手机 4G／5G 的秒数承诺。

## 修改顺序与边界

1. 列表、对比和小图采用 512 像素缩略图；详情与下载保留大图。
2. 私有 ETag 条件缓存，权限先检查再返回 304，撤销批准和退出立即拒绝。
3. 员工／管理员在服务器搜索、归并系列后分页，复用与前端相同的查询规则，保留多选、编号、中英文、搜图、收藏、跨页对比、编辑和导出。
4. 客户手机公司图片和轮播使用轻图，PC 与完整查看维持原图。
5. 复用安全投影／员工查询索引，文件按块传输，GET／HEAD 持久连接，POST 提前拒绝后关闭连接。
6. 仅优化正式域名 Nginx 的 HTTP/2 和后端连接复用；不改变用户、密码、登录保护、域名或已批准的产品范围。

## 验证

- 合成 HTTP 回归覆盖缩略图大小、元数据清除、原图下载摘要、304、退出／撤销批准后拒绝、持久 GET、POST 提前拒绝、索引故障重建、编号／分页／收藏／导出与公式前缀保护。
- DOM 回归覆盖首次不下载全库、系列规格、跨页比较、精确编号、容量别名、筛选、新旧请求顺序、收藏移除，以及分页模式下管理员深链接、版本保存和归并规格刷新。
- 原有角色隔离、登录、搜图、后台、移动页面、中英文和所有项目测试继续运行。
