# 源泽灵感选型 · yuanze2.0.2

**本地交互 demo，未上线。** 原生产 `/client`、登录、包材检索和后台均未修改。

## 设计方向

以 Apple 应用的系统排版、细边框、圆角窗口和侧边栏组织 38 张既有客户海报。玻璃材质用于工具栏与弹出面板，海报完整显示。保留源泽原标志。

参考用户 Chrome 中的 Figma「iOS and iPadOS 27 (Community)」Materials 面板、Apple HIG Typography/Materials，以及 React Bits Circular Gallery / Accordion Gallery 的浏览方式。当前交互为独立 React/CSS 实现，没有安装 React Bits，也未复制 Figma 组件或字体文件。

## 可操作内容

- 中英文、用途分类、风格筛选、标题搜索与无结果恢复。
- 画廊与总览；左右按钮、键盘左右键、横向拖动和缩略图切换。
- 收藏及选型条件保存到本机浏览器，刷新保留；可以移除。
- 大图、按需读取原图、加载状态/失败重试、200% 缩放与原图下载。
- 桌面右侧选型面板、手机底部面板、Escape 关闭与焦点返回。
- 小屏菜单、清晰键盘焦点和减少动态效果适配。

「找相似包材」在本版打开条件面板，让用户选择整体风格或瓶型轮廓并补充备注。**没有连接真实包材匹配，不产生真实询价，不发送给业务员。** 海报风格标签只是编辑建议，不代表材质、库存、价格或配方适配。

## 运行

使用 Node.js 与 Python 3；先在本目录安装 package.json 中的依赖，再运行：

```sh
python3 prepare-assets.py
npm test
npm run build
npm run dev
```

默认地址：`http://127.0.0.1:8773/`，只监听本机。可用 `npx vite preview --host 127.0.0.1 --port 8773 --strictPort` 预览构建结果。

本机验证复用了相邻 `login-immersive-demo/node_modules` 中的相同 React/Lucide/Vite 版本；软链接、素材副本与构建目录不入库。脚本从现有已批准海报目录复制素材，不读取业务数据库或私有图册。`assets-manifest.json` 记录 115 个资源的来源摘要，`src/posters.json` 仅含客户海报展示字段。

## 2026-10-20 跟手滑动更新 · yuanze2.0.2

画廊增加指针跟手移动、松手切换与短距离回弹，支持鼠标、触摸指针及触控板横向滚动；一次触控板手势的惯性尾部不会连续翻页。纵向滚动、双指缩放、普通点击看图、键盘和按钮保留。手势开始后通过 pointer capture 接收画廊边界外的松手；取消、多指介入、失焦和筛选变化会清理临时状态。

动画只修改局部轨道 transform，并通过 requestAnimationFrame 合并移动更新；拖动过程中不重渲染 React 海报树。减少动态效果时不跟随位移，仍能切换。没有新增动画依赖。本地收藏存储键保持兼容 2.0.1。

12 项 demo 测试覆盖正常/快速/短距离/纵向/取消/多指/失去捕获、误触、触控板惯性、减少动态效果与清理。浏览器实测结果和触摸模拟限制见 `swipe-verification.json`。

本次 12 项测试、构建与主项目全套验证通过。Safari 已加载 2.0.2；实体 Mac 触控板尚未人工试用，浏览器验证使用横向 wheel 输入模拟。修正历史文件检查对旧版本已移除相对依赖软链接的误判：仅认可已核对的路径、软链接模式和 blob，不放行依赖内容或当前索引中的软链接。

## 同版本修复：Mac 连续横滑锁定

用户反馈一次横滑后后续手势卡住，上下滑一下才恢复。新增三个回归场景先在旧实现复现失败：长惯性中同向再滑、直接反向、结束定时器未解除 committed 锁定。修复为 180ms 完整状态复位，忽略亚像素尾部对锁的续期，并通过衰减后的重新加速/明确反向识别新手势；同时清理已松开的鼠标指针占用。增加微小惯性抖动及鼠标占用测试。

16 项 demo 测试、Vite 构建与主项目验证通过。CUA 浏览器连续三次同向手势得到 2/38 → 3/38 → 4/38，连续正反向得到 7/38 → 6/38 → 7/38，无弹窗误触或控制台错误。Safari 已刷新，原生滚动注入不可用，尚未进行实体触控板手感验收。记录见 `swipe-verification.json` 的 `trackpadFix`。保持 yuanze2.0.2，本地预览未上线。
