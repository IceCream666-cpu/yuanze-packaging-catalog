# 包材主图优化规范

更新：2026-10-06。当前阶段：本地样板制作，尚未替换网站图片。

## 已确认的方向

包材主图参考用户提供的暖米色场景与柔和光线。保留原包材的材质、颜色、瓶型、相对比例及配件，仅优化摄影呈现和质感美观。

## 统一画面

- 方形主图，单品居中且完整，主体高度约占画面 70%，留足边距。
- 暖米白／浅米色背景，细微哑光台面纹理，背景柔和虚化。
- 左上方柔和光源，自然落地阴影；主体保持中性白平衡，避免暖背景改变包材颜色。
- 不额外增加品牌标签、宣传文字、植物或装饰道具。
- 透明、磨砂、实色塑料、玻璃、金属等表面分别遵循原图；不把高亮塑料改成磨砂玻璃，不把普通瓶盖改成纸感材质。

## 产品信息与原图

- 原图保留，优化图另存；产品编号、规格、报价及记录不变。
- 产品本身可见的印刷文字、部件和接缝须逐一核对；模糊部位不得补出新的规格或结构。
- 手持图可移除手和背景；画册单品图可移除外围尺寸箭头、文字和页面背景，参数仍保留在产品资料中。
- 多产品图须先确认编辑对象与记录对应关系，再制作单品主图。
- 图片美化不等于客户展示审核。保留的供应商品牌或原有印刷仍遵循现有客户图片权限。

## 样板验收测试

每张原图与输出逐一对照，检查：

1. 产品主体完整，产品数量与指定编辑对象一致。
2. 瓶身、盖、泵头、胶头的形状和相对比例一致。
3. 原材质、原颜色和透明度可辨，没有借用风格参考图的产品设计。
4. 原可见印刷没有改字或新增文案，部件没有增减。
5. 背景、光源方向与留白符合统一画面要求。
6. 文件可正常解码，正方形输出；来源与产品编号可追踪，原图未被覆盖。

未通过的样板保留为草稿，记录差异后修订；不能作为正式产品图片上线。
