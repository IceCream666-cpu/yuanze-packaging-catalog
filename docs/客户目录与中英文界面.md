# 客户目录与中英文界面

员工、管理员、客户共用登录页，由服务器按照账号角色进入对应页面。各页面顶栏提供 English / 中文切换；选择保存在当前浏览器，刷新和重新登录后沿用。切换不会重建管理员正在编辑的表单，不清空筛选、输入和未保存的修改。

界面导航、按钮、筛选标签、标准类目、状态提示、分页和产品详情字段支持中英文。产品原始名称、报价原文、供应商信息、用户备注等业务内容保留原文；不会自动翻译并写回数据库。日期使用所选语言的格式。

## 客户目录

客户页面恢复完整展厅布局，提供面部、身体／头部分区，编号和关键词搜索，类别、材质、容量、瓶型、用途的多选筛选，产品卡片、图片集、详情、分页及页码跳转。相同筛选项满足任意选值，不同筛选项同时满足。搜索支持标准中英文用途和瓶型词。

客户展示使用独立的 `/api/client/catalog` 接口。公开内容只由系统产品编号、受控分类词表及完整数值规格生成；不返回供应商、联系方式、价格、MOQ、交货条件、原始文本、图册来源、内部记录 ID 或原图路径。未知材质和规格不会通过照片推断。客户不能访问员工或管理员数据接口。

仍只展示管理员明确批准 `clientVisible: true` 的图片。原图可能含有水印或供应商信息，恢复页面布局不会自动批准更多图片，也不处理水印。图片通过不含原路径的 `/client-media/` 地址发送，删除元数据并限制尺寸；取图时重新核验批准和归档状态。

## 回归与发布

- `server-reference/test_client_access.py`、`test_client_projection.py`：安全投影、搜索不命中私密原文、筛选、分页、撤销图片批准及角色隔离。
- `tests/frontend/client-ui-tests.cjs`：客户界面、详情和多图、筛选和语言状态保留、加载失败和退出。
- `tests/frontend/i18n-tests.cjs`：三端与登录翻译、原始资料不变、表单内容保留、规范值提交和动态提示。
- 发布只替换代码和静态资源，先备份生产状态并验证原会话、三种账号及登录路由。不要用本地空库覆盖线上数据库。
