# 代码去重与模型加载优化 — 本地性能候选

北京时间：2026-11-17。生产仍为 client1.57；本轮未发布，没有将072 v2混入正式目录。

## 完成内容

- 11个独立模型预览入口共用 `src/local-review.jsx`：保留各款静态配置、海报/GLB、标题、收藏键和原海报弹窗。该范围产品代码308→125行，减少183行（59.4%）。
- 首页、画廊和网格的鼠标悬停 / 主动键盘聚焦提前加载当前模型及异步代码。只允许1个预取，最长5秒；离开、失焦、切款、退出登录时取消。省流量与2G连接跳过预取；触屏按点击正常加载。
- 弹窗接收已有请求，关闭后释放；自动恢复焦点不触发额外下载。代码模块复用不保留已关闭的GLB或GPU场景。请求仍使用 same-origin、no-cache、AbortSignal；服务端权限未改。
- 清理38个未跟踪可再生文件，共8,238,726字节（8.24 MB）。缓存隔离至本工程 `.cache/vite`，避免共享node_modules缓存。磁盘清理与浏览器速度收益分别计算。

## 测量结果

线上登录后的真实页面基线见 `live-baseline.json`、`live-repeat.json`：首次记录约2.82秒，重复打开0.26–3.31秒，网络再验证波动较大。gzip、ETag与认证已生效；未以登录页、压缩未开启或单次网络值作为优化结论。

为排除线上波动，在同一Ego Lite浏览器用两个仅绑定127.0.0.1的gzip比较服务器读取同一套正式素材：旧版8881，新构建8882。模型打开阶段模拟4Mbps下载、80ms延迟，目标页缓存禁用，桌面1440×1000，各3次。首页先完成加载，测试不代表整站冷启动。鼠标悬停后固定等待500ms，再发起真实点击；连同浏览器工具动作，实测悬停至点击约1.1–1.2秒，原始值保留在JSON。

| 从点击到模型第一帧 | 旧版 | 优化版 |
|---|---:|---:|
| 第1次 | 3.155秒 | 2.043秒 |
| 第2次 | 3.111秒 | 1.909秒 |
| 第3次 | 3.119秒 | 1.908秒 |
| 中位数 | 3.119秒 | 1.909秒 |

中位数缩短1.211秒，约38.8%。六次均只有1个GLB请求。收益来自把等待前移至明确浏览意图阶段；模型下载字节数不变，直接点击/手机点击不保证同幅度收益。这是模拟网络实验，不是线上真实用户指标或真机测试。

## 可复现与文件

`serve_comparison.py`只用于本地性能比较，不包含业务数据，不可作公网服务。运行：

```sh
python3 docs/client-motion-demo/review-evidence/loading-20261117/serve_comparison.py --port 8881
python3 docs/client-motion-demo/review-evidence/loading-20261117/serve_comparison.py --port 8882 --candidate /private/tmp/yuanze-loading-20261117/candidate-build
```

`measure.mjs`记录浏览器操作；执行前将TaskSpace编号改为自己当前目标空间，variant切换baseline/candidate。脚本在finally恢复网络/缓存测试设置。服务器已用HTTP检查gzip解压、ETag 304及路径穿越/非展厅路由404；候选构建哈希见 `candidate-build-hashes.json`。

保留共享依赖缓存、跟踪的release/.vite清单、模型源档、正式资源及全部回退备份。缓存会在下一次开发运行时按需重建。用户浏览器cookie和个人缓存未清理。
