# 包材库 32 款 3D 模型质量审查

整理日期：2026-11-17。独立审查；本轮没有修改或发布模型。

## 范围与证据

- 基线为 client1.56：32 个正式模型、31 款首页精选、68 张海报。080 模型仍在库内，首页使用 082 洗护组合替代独立展示，并非少算一款。
- 2026-11-13 完成每款合拢、半展开、完全展开、旋转 90° 的浏览器截图，共 128 张主截图；使用相同的网页渲染器、正式模型文件和各款既有配色，审查画布为 1237×982 CSS 像素。统一画布不等同于逐款完整页面或手机布局验收。
- 11 月 13 日 17:34 的只读线上核验确认全部 32 个模型哈希与本地一致。11 月 17 日重新核验本地 32 个文件均未变化；本次未重新建立线上连接，不能把旧核验时间写成今天。
- 32 个主模型都完成上述四种状态；080 的白色 Soap 场景已看，After/Baby 另外两个切换场景仅核对了资产配置，尚未补做浏览器视觉验收。额外底部/背面截图不齐，不计入全量覆盖。
- 原海报有料体，模型按此前要求展示空包材：缺少油、蓝粉料体或胶囊不算错误。内部工程结构属于展示示意，不能从图片推导制造尺寸。

## 结论与优先级

有明显提升空间，但多数瓶型可以保留。建议先处理 5 款，其次精修 19 款，另 8 款保留主体做局部微调。该分组是视觉与结构改善顺序，不是制造质量评级。

**先处理 049、072 的吸管遗漏，再处理 012 的分层一致性，随后优化 056、084 的材质可读性。**

1. **结构遗漏：**049 Moisture Shampoo、072 Daily Emulsion 没有长吸管。已结合展开截图和 GLB 节点检查确认。补入吸管时与泵头一起移动，保持客户易理解的完整组件。
2. **分层一致性：**012 最早版本主要只让 Logo 飞出，标贴和产品名仍留在瓶身。应与后来的底材、文字分层方式对齐。其余款不能只看“是否移动”，还要看完全展开后是否仍可理解层级。
3. **材质层次：**部分透明玻璃轮廓过淡、厚底缺少层次；056 深色盖子像纯色板；白色泵头常与背景接近。这些先调光和材质，再决定是否改几何，避免整款返工。
4. **标贴投影：**共享渲染代码对透射玻璃关闭接影，对带贴图的面通常关闭投影。32 款配置中仅 067、068、071、085 显式启用 labelShadows。该数字不等于另外 28 款全部没有阴影，但说明新投影规范尚未成为全库统一规则。需要逐款区分实体纸标、透明膜和文字，检查半展开时瓶身接影；不能把透明文字承载面投成黑色矩形。
5. **表面细节与性能：**没有必要统一增加面数。051 约 24.7 万三角面、067 约 23.4 万，084 含 212 个 mesh；这是资产复杂度，不是实测卡顿结论。优先保留轮廓、绳结和可见结构，把纸纤维、磨砂等微观质感放在合适的材质细节中，并在优化前后对照浏览器实际画面。

## Blender 与网页效果的关系

当前共享网页代码会重新设置粗糙度、透射、厚度、高光及投影。比如部分滴管使用透明度合成近似，地面也使用渐变阴影平面。因此，Blender 源场景变精细并不会自动保证网页得到相同效果。后续每款应将 Blender 外观、导出的模型及网页实际渲染一起验收。

无需再次把泵头拆成按头、泵杆、旋盖等零碎层级。建议保留当前“完整泵头/盖子 + 瓶身 + 标贴底材 + 外层文字”的客户展示逻辑，把精修重点放在可见的曲面、接合处、材质区别和对应阴影。
