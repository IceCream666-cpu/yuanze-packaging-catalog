# client1.31 手机交互与加载修复

状态：本地预览，未发布。基线是已发布 client1.30（2dbcfef）。本轮没有服务器、网关、业务数据库或账号变更。

## 改动

- 900px以内且粗指针的模型展开轨道从300svh缩至200svh，即滚动行程从两屏缩至一屏。关闭手机叠加的220ms scrub缓动，场景展开进度跟随原生滚动。
- 真实touch输入旋转增益0.015→0.0225 rad/px，拖动直接跟随；5px方向判断后上下滚动不误旋转。鼠标系数及缓动保持原值。
- scrub:true下GSAP getTween返回false，两个刷新/即时跳转调用点改成可选方法调用；浏览器发现该问题后补了真实false返回的回归。
- 图片队列正常两项并发，新选中产品可以使用一个有界优先位置，最多三项；保留已经开始的请求和解码节点。
- 登录手机模糊背景192×256、最多10fps；清晰面板仍使用原20fps视频。重复帧不再复制，Canvas及异步视频失败时回到静态图，旧媒体查询监听兼容，账号密码逻辑不变。
- 模型首开GLB/场景/详情并行，既有ETag鉴权缓存保留。未新增跨账号模型内存缓存，未声称本轮降低首次模型下载耗时。

图片队列26产品确定性测试：两个旧请求等待时选择新产品，旧版保持idle，新版立即loading；继续快速切换总在途不超过3，最新选择取得下一位置。没有以测试推断运营商下载速度。
