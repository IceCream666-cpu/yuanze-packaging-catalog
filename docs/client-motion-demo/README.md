# client1.1 · 沉浸式海报展台

状态：本地设计预览，尚未替换线上 `/client`。以 `deb02b2` 的 client1.0 为基线，独立源码位于本目录；正式入口、认证服务、业务接口和发布清单仍由既有 client1.0 管理。

## 本版设计

将用户指定的滑动效果用于现有海报：中间海报按原比例完整显示，相邻海报缩小、轻微转向并保留浏览线索；拖动时跟手移动，释放后吸附。背景取自当前海报的柔和色系，标题、计数和缩略图跟随选中项切换。原源泽标志、系统字体及深绿色文字沿用现有品牌。

支持鼠标拖动、手机横滑、触控板横向 wheel、方向键、前后按钮和底部缩略图。纵向滚动留给页面；横滑惯性尾段不连续跳过多张。遵循系统减少动态效果设置，减少时立即对齐到选中海报。

保留六类用途与全部海报、视觉风格筛选、中英文标题检索、画廊/总览、本机收藏、高清原图、加载失败重试、缩放和原图下载。收藏继续使用 `yuanze2.0.1.demo.favorites.v1`；同一浏览器同一源更新时可继承。不同预览端口属于不同浏览器源，不能直接读取线上收藏。

## 素材

38 张海报全部来自现有 `server-reference/public/showroom/product-posters.js` 和已批准的 `bundle-manifest.json`，与 client1.0 一致。分类：面部 10、洗发护发 10、身体 10、香氛 3、套组 4、口腔 1。

`prepare-assets.py` 仅复制源文件，生成 38 份预览、38 份缩略图、38 份原图和原始 logo，共 115 个资源；不裁切、不重绘、不替换文字或标志。测试逐项验证 SHA-256、字节长度及批准清单。风格分类是已有视觉整理，不推断 SKU、供应商、库存、价格或产品功效。

## 本地运行

在本目录安装 package.json 中锁定版本的依赖后：

```sh
python3 prepare-assets.py
npm run dev
```

打开 `http://127.0.0.1:8784/`。构建：`npm run build`，输出 `dist/`。构建资源使用相对路径，可由任意本地静态服务器预览。

默认预览不请求业务 API。源码保留原有 session/CSRF 退出适配供后续整合；当前 Vite 配置与正式发布脚本均未切换到此版本，不能直接把本预览当成线上权限实现或已发布版本。

## 验证

```sh
npm test
node tests/browser-interruptions.cjs
```

第二条需已运行的本地预览及 Playwright/Chrome，可用 `QA_URL` 指定地址。仓库根目录 `scripts/verify.py` 已纳入本版 13 项模型、筛选、收藏和素材回归；浏览器验证记录见 `verification.json`。

视觉检查覆盖 1440、768、390 和 360 px；实际浏览器模拟鼠标、触摸和 wheel，不能等同于实体 Mac 触控板体验验收。布局允许完整海报浮起的阴影，因为立体滑动是用户指定效果；页面保留略大的展厅标题。手机分类在独立区域横向滚动，文案不造成整页横向溢出。

## 维护

主要文件：`src/main.jsx` 管理检索/收藏/大图；`src/PosterStage.jsx` 管理拖动与吸附；`src/carousel-model.js` 管理循环窗口与惯性目标；`src/poster-palettes.json` 管理每张海报的背景配色；`src/style.css` 管理桌面与手机布局。

后续替换正式客户端时，需要复用当前认证资源路径和 manifest 发布流程，重新构建、核验权限及线上资源；本设计预览没有执行生产发布。
