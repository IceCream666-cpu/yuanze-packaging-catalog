# 085 写实渲染修订

用户明确要求本机 Blender、有阴影、高质量、接近真实肉眼观感。延续已确认一瓶一管及六组结构，不改变品牌、文案或瓶型比例。

使用 Cycles 路径追踪、真实地面、四盏面积灯和85mm透视相机。低强度环境光保留明暗层次；接触阴影落实瓶底；铜棕表面采用细微粗糙度变化，奶白塑料采用少量次表面散射和柔和高光。地面为暖色哑光摄影台面，不加入无关道具。

先渲染900×1100照明校样，再输出2400×3000、16位PNG正面与展开图，512采样上限、自适应阈值0.006、降噪。保存独立photographic-v2 .blend，保留1/31/61帧及六组可编辑模型。网页实时模型与Cycles成片是不同渲染方式，本次不声称浏览器达到离线渲染质量；未发布。

验收：检查真实保存文件中的场景、灯、地面、相机、材质、内嵌纹理、分组动画；目检结构、字标、底部落地、阴影方向、反光不过曝、无裁切。参考图没有实测尺寸、实际材质样片和灯光信息，不能保证与实物视觉完全一致。
