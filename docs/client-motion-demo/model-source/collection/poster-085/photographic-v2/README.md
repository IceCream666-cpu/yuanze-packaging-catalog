# Daily Hair Ritual · Blender 写实场景 v2

范围：poster-085 铜棕泵瓶与玫瑰棕软管，一瓶一管、空包材。原始 v1 模型及网页交互预览保留；本目录是独立 Blender Cycles 摄影场景，未发布。

## 文件
- `poster-085-photographic-v2.blend`：可编辑摄影场景，包含六组模型、动画、相机、四盏面积灯、真实接影地面、无缝背景及内嵌印刷纹理。
- `Daily-Hair-Ritual-Cycles-2400x3000.png`：合拢状态，2400×3000、16位 PNG。
- `Daily-Hair-Ritual-Cycles-expanded-2400x3000.png`：完全展开状态，同规格。
- `render-info.json`：实际渲染参数。
- `verification.json`：重新打开保存的 .blend 后执行的场景校验。

## 在 Blender 中查看
时间轴 1 帧为合拢、31 帧为半展开、61 帧为完全展开；相机、接影地面和无缝背景随展开取景。六个产品组仍可单独选择编辑。数字键盘0查看相机，F12以当前帧重新渲染。高质量渲染使用Cycles；当前场景为摄影展示，不是生产尺寸CAD。

## 本次改进
- 实际地面承接产品投影与瓶底接触阴影，背景使用弧形无缝摄影台。
- 主光与补光分离，降低环境光，保留铜棕表面的明暗和反射层次。
- 奶白塑料细微粗糙度与少量次表面散射；铜棕、玫瑰棕表面使用微观凹凸和粗糙度变化。
- 泵嘴表面细分平滑；透明空心吸管使用折射材质。
- 85mm透视相机、f/11景深；Cycles512采样上限、自适应阈值0.006、降噪、AgX色彩管理。

## 复现
在上一层目录保存的 `poster-085-v1.blend` 上运行 `../render_photographic.py`。`-- preview`生成照明校样，`-- --scene-only`只重建并保存摄影场景；完整运行输出两张高清图。`../verify_photographic.py`在新保存的 .blend 内运行作交付检查。

边界：仅从参考图推定材质与外观，未做实物测量/色卡校准。Cycles离线成片和浏览器实时GLB是不同渲染方式，不能把成片当作实时网页质量验证。

验收完成：两张最终图均目检；实际重开源文件检查通过。修复了展开时背景与下降地面的接缝。Mac可用时默认Metal GPU，其他环境回退CPU；本次合拢图CPU、展开修正版Metal GPU渲染。
