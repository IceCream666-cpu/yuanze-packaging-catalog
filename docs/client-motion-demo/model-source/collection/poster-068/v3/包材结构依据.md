# 精华水包材基础与本款选择

查阅日期：2026-11-13。只采用供应商资料；不以商品海报推断未拍到的真实结构。

## 资料支持的基础知识
1. 精华水品类不能单独决定使用泵还是旋盖。COSPAKS 的玻璃 toner bottle 类目同时提供旋盖配内塞、翻盖及碟顶盖等选项，要求按瓶口规格选配。来源：https://www.cospaks.com/product-category/glass-cosmetic-containers/toner-bottle/
2. 玻璃精华水瓶采用 screw cap + plug/reducer 是现有供应商方案。FINSPOT 页面展示这一组合，但其容量/尺寸不是本款的生产依据。来源：https://www.finspotglass.com/glass-lotion-bottle/cosmetic-glass-bottle-screw-cap-30ml.html
3. 控流塞通常压入瓶口，通过较小孔口倒出；是否匹配某一瓶颈必须确认。Berlin 这个具体 LDPE SKU针对塑料瓶，不能直接宣称可配我们的玻璃瓶。来源：https://www.berlinpackaging.com/ldpe-push-in-orifice-reducers/
4. 外盖造型、内盖锁合、瓶颈及出液件承担不同功能；一个外观盖网格不能说明密封和出液方式。将内部件建出，不代表必须在客户展示中把它们逐一拆开。

## 本款采用的展示方案
参考图可确认：扁方透明瓶、厚底、淡紫折面盖、银色颈圈、200 ml文字。不能确认内塞样式、材质牌号、螺距和密封面。
因此采用倒取式方案：玻璃螺纹瓶颈＋带贯通孔内塞＋有内螺纹与封孔件的完整外盖。银圈留瓶；内塞可单独展开说明出液，盖内部件整体移动，维持三个主要机械组件。
