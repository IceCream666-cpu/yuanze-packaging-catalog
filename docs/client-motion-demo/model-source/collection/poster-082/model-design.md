# Soap Clean Duo · 展示级模型说明

本地审查模型依据已批准的 `soap-clean-duo-v2.png` 和第 4 张原始参考制作，含 180 ml 奶白软管与 300 ml 奶白圆盘泵瓶。使用本机 Blender 5.4.0 Alpha 实际构建并导出 `.blend` 和内嵌贴图的 GLB。

软管采用由圆润下端渐变到扁平热封尾的柔性外形，保留细浅蓝条纹、封尾压纹、底盖翻盖接缝和指扣。泵瓶为不透明奶白塑料圆柱，平缓肩沿和圆润底边；浅蓝泵顶为宽薄圆盘，后缘仅保留低矮扁短凸片。没有料体、玻璃瓶或纸标。

客户视图使用六组：容器、完整泵头、完整软管盖、条纹与透明印刷承载、liaose 字标、产品名称与容量。泵盖、内部连接座、透明中空长吸管保持同一组。胶管的外径为 0.082 个场景单位，内径为 0.058；吸管末端中心高 0.115，瓶内底高 0.089。字标与文字比印刷承载面更向外移动。

比例采用海报目测推定：软管总高 3.105、封尾宽 1.40、底盖宽 0.80；泵瓶含泵总高 2.6545、瓶身直径 1.15；两件中心间距 1.58。场景单位不代表实测毫米尺寸。背面、内壁、螺口和泵内部连接结构为展示推定，不作为模具或生产 CAD。

重建：在仓库根执行 `/Applications/Blender.app/Contents/MacOS/Blender -b --python-exit-code 1 --python docs/client-motion-demo/model-source/collection/poster-082/build_soap_duo.py`。构建会读取同目录 `review-product.json` 作为展示展开配置，并写入对应动画帧 1、31、61。GLB 只导出合拢静态组件，由现有网页查看器控制交互展开。

本地 Blender 静帧只用于几何和视觉核对；浏览器旋转、合拢/展开、重复载入与模拟窄屏验收由主代理单独记录。此模型不代表已上线。
