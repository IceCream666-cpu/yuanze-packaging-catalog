# 客户海报展示探索 · yuanze2.0.1

2026-10-20。用户确认核心路径：**选中喜欢的风格，再找相似包材**。

本目录保留三个最初的静态构图方案：

| 方案 | 主要体验 | 适用场景 |
| --- | --- | --- |
| explorer.html | 风格探索器，海报与筛选同步 | 新客户快速缩小方向 |
| gallery.html | 沉浸主题展厅，大幅海报逐张浏览 | 以产品视觉激发需求 |
| board.html | 灵感搭配台，收藏后比较 | 已有多张偏好参考 |

以上是布局草图，不表示已有包材匹配结果，也未部署到客户网站。

用户随后提出 Apple 应用边框、字体和交互，并提供 Chrome 中打开的 Figma「iOS and iPadOS 27 (Community)」参考。当前实现转为 [Apple 风格交互 demo](../client-apple-demo/README.md)，不是用户在三项中作出了选择。

本地 demo 使用现有 38 张客户海报，保留源泽标志。实现侧边栏、画廊/总览、用途与风格筛选、收藏、高清查看、选型条件面板。风格标签为本轮编辑建议，真实包材检索和账号数据仍待接入。

此前比较页面 `127.0.0.1:55284` 仅作探索记录；本轮可操作预览入口为 `http://127.0.0.1:8773/`。
