3. 包材图片须显式批准 `clientVisible: true`；不因产品已有一张获批图片，就自动批准其余图片。每次取图重新核对批准状态与是否归档，派生图片清除元数据并使用不透明地址。
4. 客户专用搜索、对比、导出和跨页消息都遵守同一安全边界。客户账号不能访问员工目录、管理员 API、原始图片路径或业务演示。
5. 公司照片、证书 PNG 和原始 PDF 在正式客户展示中也须登录后访问。仅 `/client/products` 允许同源嵌入，其余页面保留防嵌入保护。内嵌产品页点 Logo 通知外层切回首页；登录失效通知外层跳转统一登录页，防止出现空白 iframe。消息必须来自同源的指定产品窗口，不能指定任意跳转地址。
6. 图片中的水印文字不能靠数据字段过滤消除。目前不批量去水印；用户后续替换素材。未经批准的图片不得为了填满页面自动放行。
7. 当前收藏、意向清单、对比仅存页面内存，刷新或关闭后清空。公共客户账号下，不把某人的清单存入全体客户共用账号的数据中。
