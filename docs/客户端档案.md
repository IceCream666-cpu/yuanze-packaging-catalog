# 客户端档案

维护日期：2026-10-07。本文用于后续通过对话说明客户界面的改动；修改时应同时更新实现、测试和本档案。产品海报栏目首次于北京时间 2026-10-04 03:40 上线，源码提交为 `bc5ebdf5a10a16321f061a18e48607cd17231545`；后续代码与图片发布见本文后段及《发布记录》。2026-10-07 16:22（北京时间）新增 10 张海报正式上线，素材提交 `46e3891`。随后按用户示例移除同系列女性模特横版海报 17 张，17:02 正式发布完成，当前展示 24 张；验证及发布状态见下方移除记录。

## 服务对象和目标

客户登录后认识源泽、查找包材、比较规格并整理意向清单。沿用源泽 logo 和深青绿、暖象牙白配色，提供中英文切换。公司简介、展厅、前台与中英文 ISO / GMPC 证书使用已提供素材。

客户不应收到包材供应商、联系方式、采购成本或具体报价。这里的“联系”指源泽业务员或公司接待，不是包材供应商。

## 产品海报栏目（2026-10-04 已上线）

- 产品入口 `#/products` 默认进入海报，`#/products/catalog` 进入原包材库。主导航仍是首页／产品／联系三个分页；PC 顶栏、手机底栏保持一致内容和权限。
- 累计收到三个压缩包 33 张图片及 10 张直接附件，去除 2 张完全重复图后共 41 张来源；用户要求删除同系列女性模特横版海报后，当前展示 24 张，移除 17 张。分类为面部护理、头发护理、身体护理、香氛、口腔护理、护理套装；一张海报是一项展示，不推断对应包材 SKU、库存或价格。
- 列表使用最大边 640px 缩略图并延迟加载，24 张缩略图合计约 0.87 MB；点开才加载无损高清 WebP，保持原文字、标志、配色和构图。标题及导航支持中英文，海报内文字沿用用户提供版本。
- 点击海报可放大、上一张／下一张；浏览器返回／前进恢复类别和海报。包材页第一次进入才加载，之后在海报、首页和联系间切换保留原 iframe 的筛选及本次选型状态。页面刷新后的清单持久化规则保持原有边界。
- 海报和脚本都通过 `/showroom/` 登录保护；客户和管理员可看，员工继续原工作区。新增海报不改变原客户包材图片批准范围，也不开放价格或供应商字段。
- 修改方式：更新海报数据、素材清单和 `assets/manifest.json` 后运行 `scripts/build_customer_showroom.py`，再运行全量验证。原 ZIP 不进入发布目录；素材来源及原像素摘要用于追溯。海报的网页后台编辑尚未实现，目前通过本项目文件维护。

## 包材功能清单

| 功能 | 实现与边界 |
| --- | --- |
| 搜索 | 系统产品编号、标准材质、容量、瓶型、用途；不能搜索供应商等私有字段 |
| 分类 | 面部、身体／头部与检索条件联动；包材类型、分区、材质、规格、瓶型、用途均可多选 |
| 多选规则 | 同一筛选项内满足任一值，不同筛选项同时满足；已选条件可移除或重置 |
| 手机筛选 | 可展开或收起；搜索栏始终可访问 |
| 浏览 | 网格／列表、每页 12／24／48 项、上一页／下一页和指定页码跳转 |
| 图片与详情 | 至少一张已批准图片；多张时显示数量并可切换。显示编号、标准分类、净含量、材质、用途和有依据的数值规格 |
| 图片检索 | 客户专用接口，仅返回当前可供客户展示的匹配图片和资料，最多 48 项；不返回内部索引数量、图片原路径或评分 |
| 收藏 | 本次页面内保存，可查看、取消和继续筛选；不是账号级云端收藏 |
| 意向清单 | 多款加入／移除，切换到联系页可整理咨询；不自动提交询盘，也不自动联系任何人 |
| 对比 | 最多四款，对比图片及公开规格，不显示成本、供应商或来源 |
| 导出 | 导出当前页或意向清单的公开字段 CSV；不等于员工的完整内部资料导出 |
| 中英文 | 页面、按钮、标准分类、咨询提示与证书语言联动；语言切换保留当前页面、筛选、清单和备注 |

“保留选型功能”不等于开放内部报价状态、供应商来源图册、员工记录 ID、样品借还记录或原始询价单。这些内容不属于客户数据出口。

## 数据与权限的硬性边界

1. 客户响应由 `client_catalog.py` 按允许字段重新构建，不能把员工目录取回浏览器后仅用 CSS 隐藏价格。
2. 对外名称由标准分类／瓶型／容量组合，自由文本、OCR 原文、内部型号、来源文件名、联系方式和历史报价不直接透出。
3. 包材图片须显式批准 `clientVisible: true`；不因产品已有一张获批图片，就自动批准其余图片。每次取图重新核对批准状态与是否归档，派生图片清除元数据并使用不透明地址。
4. 客户专用搜索、对比、导出和跨页消息都遵守同一安全边界。客户账号不能访问员工目录、管理员 API、原始图片路径或业务演示。
5. 公司照片、证书 PNG 和原始 PDF 在正式客户展示中也须登录后访问。仅 `/client/products` 允许同源嵌入，其余页面保留防嵌入保护。内嵌产品页点 Logo 通知外层切回首页；登录失效通知外层跳转统一登录页，防止出现空白 iframe。消息必须来自同源的指定产品窗口，不能指定任意跳转地址。
6. 图片中的水印文字不能靠数据字段过滤消除。目前不批量去水印；用户后续替换素材。未经批准的图片不得为了填满页面自动放行。
7. 当前收藏、意向清单、对比仅存页面内存，刷新或关闭后清空。公共客户账号下，不把某人的清单存入全体客户共用账号的数据中。
