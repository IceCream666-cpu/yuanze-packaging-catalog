## 设计与边界

- 沿用已确认登录页的炭黑框架、白色圆角工作面及单一搜图按钮的彩色边线，原源泽标志不变。图片完整显示，不裁去瓶型，不加滤镜。
- 列表回答“哪款包材适合当前用途和规格”；详情回答“当前规格的裸瓶价、条件及工艺是什么”；对比保留原文条件，不能仅凭最低数字判断。
- 使用现有分页、图片、搜索、收藏、规格、对比、导出和后台权限。不保存本地产品副本，也不读取其他工程目录。

- 本地页面使用真实数据。收藏、保存方案等原有操作仍会写入真实账号；本轮浏览器验证仅使用查找、规格、对比等不写业务数据的动作。
- 简单“普通报价：数字”按用户确认口径显示裸瓶价，原文保留。复杂条件、币种、区间和多档报价不做数字猜测，继续呈现原文。
- 快捷用途调用既有搜索提交，不创建新分类或更改模型。取消旧列表装饰动画，不引入视频或全屏动态模糊。

## 实现

`workspace.css` 全部限定 `immersive-workspace`；`workspace.js` 只装饰既有 DOM，保留节点和事件处理器。新增节点用 textContent 写入数据，观察器在装饰时断开，防止循环渲染；语言切换和分页后自动更新。

设计使用桌面 Impeccable / design-taste-frontend。Framed sheet，seed 1300132893，保留登录页配色和字体。用户确认的深色外框与局部彩色边线优先于技能的纯中性默认。原产品图与资料是界面主体，不添加统计仪表板、虚构指标或额外主视觉。抽取的 list count cards / detail charts 不适合真实包材任务，按既有产品网格和规格详情组织。
